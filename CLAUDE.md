# CLAUDE.md

Static GitHub Pages site (no build step). See README.md for how items are added.

- This site is **public**. Before adding or pushing anything, check it contains no
  confidential Encoura content (internal docs, customer/student data, analytics,
  credentials, unreleased product work). If unsure, ask instead of publishing.
- Every new page needs `<meta name="robots" content="noindex, nofollow">`.
- Each item lives in its own folder with an `index.html`, plus an entry in `items.json`.
